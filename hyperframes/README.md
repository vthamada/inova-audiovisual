# HyperFrames

Este diretório contém o adapter visual e a composição versionável `pacto-reel`. Os arquivos de mídia, assets e dependências são acessados localmente por links ignorados pelo Git; eles não são duplicados nem incorporados à composição.

A composição deve usar dependência local, identidade oficial e passar por lint, validate e inspect antes de preview ou render. Render final permanece dependente de `approval.json` válido.
